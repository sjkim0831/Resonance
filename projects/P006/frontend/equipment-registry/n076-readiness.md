# N076 설비 연결 준비도

확인일: 2026-09-29 · 대상: N076 유압 딥드로잉 프레스

## 확인 결과

N076의 원본 USD 진입 파일과 참조용 웹 GLB, 카탈로그 렌더 이미지가 있습니다. 다만 이것만으로 특정 제조사의 실제 설치 장비와 동일하거나 딥드로잉 공정에 적합하다고 승인할 수 없습니다.

| 자료 | 관찰값 | 판정 |
| --- | --- | --- |
| 원본 USD | 1,655 B · SHA-256 `2305c053b836b6b0483cb6a8d4bf034bd2e450dea6e7d1c615f641f32e780f8a` · `/Catalog/N076` 참조 | 카탈로그 참조 전용, 원본 형상 무수정 메타데이터 |
| 웹 GLB | 34,276 B · 66 Node · 21 Mesh · 392 Triangle · Material 0 · Animation 0 | 웹 시연용 저상세 형상, 실물 대조 미검증 |
| 카탈로그 이미지 | 640×480 · 85,419 B | 렌더 이미지. 실물 사진이나 특정 장비의 명판 증거가 아님 |
| N076 이름의 매뉴얼/사진/동영상/STEP | 검색 범위 안에서 발견되지 않음 | 실제 장비 정보 미확인 |

GLB의 구성요소 이름에는 프레임·하우징·하부 금형·가동 플래튼·램·타이로드가 있습니다. GLB 애니메이션은 없습니다. 따라서 정지 형상은 확인할 수 있지만 가동부 동작과 프레스 힘, 실제 크기, 설치 방향은 검증하지 못했습니다.

현재 저장된 자동차 시연 계획의 차체 패널 성형 설비는 **E096 소형 프레스**입니다. N076는 해당 계획에 연결되지 않았습니다. E096을 N076로 교체하거나 N076를 추가하려면 장비 식별과 공정 배정이 필요합니다.

## 다음 진행에 필요한 입력

1. 제조사와 정확한 모델명 또는 현장 설비 ID
2. 확보된 정면·측면·명판 사진
3. 매뉴얼·도면·CAD/USD/GLB·동작 영상 중 보유 자료
4. 확인된 주요 치수와 정격 프레스 힘; 자료가 없으면 UNKNOWN 유지
5. 자동차 계획에서 E096을 N076로 교체할지, 별도 공정 설비로 추가할지

자료가 없는 항목은 추정값으로 채우지 않습니다. 임시 등록은 UNKNOWN 및 검토 전 상태로만 둘 수 있습니다.
