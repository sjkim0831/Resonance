실제 연결된 설비 GLB와 FUNCTIONAL_DEMO 모듈을 공정 시간표에 맞춰 함께 표시합니다. 모듈은 해당 공정 설비의 작업 지점으로 이동하고, 부지 간 운송 시간에는 공장 사이를 움직이며, 조립 시간에는 조립 지점으로 모입니다. 작업점 좌표와 조립 형상은 시연용이고 물리적 Port 연결을 뜻하지 않습니다. GLB 동작 Clip이 없는 설비는 정적으로 보입니다. 아래 공정 카드에는 시작 전부터 종료 후까지 제품·부품·공장·예정시간·설비/모델 상태를 전부 표시합니다. 실제 모델이 없는 공정 카드의 `후보 모델 미리보기`는 Asset Registry GLB를 참고용으로만 표시하며 설비 배정·차종 적합성 승인·작동 검증이 아닙니다.

    진행 순서: 제품과 주요 부품 → 부지와 공장 → 공정과 운송 → 실행 검토. 위 단계 탭으로 언제든 이동할 수 있습니다.

    공정별 연결표: 시간표에 포함된 구매·제작·운송·조립·검사 단계를 나열합니다. 공정 단계의 설비 연결은 ‘공정·설비 연결 편집’에서 Asset ID와 모델 경로를 입력한 뒤 적용하세요. 설비 미지정·GLB 미연결은 실행 화면 동작도 미연결로 표시됩니다.

    모델 현황: 완제품·부품의 실제 GLB가 미연결이면 자동차 예시에 한해 별도 FUNCTIONAL_DEMO 3D 모듈을 표시합니다. 생성 형상은 USD/GLB 원본이 아니며 실제 제품·차종·부품 사양을 대표하지 않습니다. 설비 후보 Asset ID와 모델 경로가 있어도 자동차 공정 적합성이 확정된 것은 아닙니다.

    모델 경로 점검: 공정·운송의 USD 연결 영역에서 GLB 경로를 반영한 후 점검 버튼을 누르면 같은 P006 웹 자산 경로의 HTTP 응답과 파일 앞부분 서명을 확인합니다. 전체 모델 파싱, USD 내용, 차종/BOM·공정 적합성은 판정하지 않습니다.

    전체 공정 재생: 실행 검토에서 ‘전체 공정 애니메이션 재생’을 한 번 누르세요. 3D 모듈과 부지별 카메라를 준비하고 0분부터 마지막 출고까지 함께 실행합니다. 도중에는 일시정지·다음 단계·배속을 쓸 수 있습니다. 일시정지 후에는 ‘이어서 재생’으로 현재 시간부터 계속합니다. ‘일정만 실행’은 2D 시간표·흐름도만 재생합니다.

    3D 설비 공정 표시: 실행 중인 공정 설비에는 주황색 바닥 하이라이트가 나타나고, 현재 작업 설비 목록의 ‘보기’를 누르면 카메라가 해당 설비로 이동합니다. GLB Animation Clip이 있으면 입력 시간표에 맞춰 재생하지만, Clip이 없으면 설비는 정적 표시이며 하이라이트는 공정 상태 표시일 뿐 기계 동작이 아닙니다. 자동차 공정/설비 적합성은 별도 검증 대상입니다.

    E096 동작 Pilot: Asset ID가 E096이고 GLB에 bed·ram·tool Mesh가 확인되면 배정된 공정 시간에 맞춰 시험 왕복과 FUNCTIONAL_DEMO 작업물을 3D 화면에 표시합니다. Geometry에서 계산한 Stroke는 후보이며 제조사 스트로크·실제 기계 동작으로 검증되지 않았습니다.

    입력 기준: 부품 수량은 완제품 1개당 수량이며, 시간·거리 값은 검증된 실측치가 아닌 설계 가정으로 취급합니다. 기준 출처를 제품 정보에 함께 적어두세요.

    시연 범위: FUNCTIONAL_DEMO는 일정 연동 UI 동작 검증입니다. 실제 생산 BOM, 기계동작, 물리 법칙, 작업물 경로, 실제 생산능력의 적합성을 보증하지 않습니다.

    저장: 설계 파일은 JSON으로 내보내거나 가져올 수 있습니다. 서버 저장은 연결된 저장 기능이 제공될 때만 사용하세요.

    전체 공정 3D 카메라 도움말

    부지별 동시 카메라는 부지마다 독립된 카메라와 표시 대상을 가집니다. 각 카드에는 설비 대상 수, Asset+GLB 연결 수, 3D 로드 수와 미연결 공정명이 표시됩니다. 메인 3D의 공정 카드는 시작 전·진행 중·완료 후 모두 유지되며 제품, 작업 부품, 부지/공장, 시간, 실제 설비/GLB 연결 상태를 함께 표시합니다. ‘설비 보기’는 로드된 설비를, ‘작업점 보기’는 설비 모델이 없는 주황색 위치표식을 확대합니다. 공정 시작 전과 전체 완료 후에는 전체 배치를 보여주며, 진행 중에는 활성 설비를 추적합니다. 일반 드래그는 회전, Alt+드래그는 카메라 위치 이동, 휠은 확대/축소입니다. 설비 모델이 배정되지 않았거나 GLB가 로드되지 않은 작업점은 실제 설비로 세지 않습니다. 카탈로그 후보 연결은 시각화 참고이며 자동차 공정 적합성이나 기계 동작 승인과 다릅니다.

    공정별 설비 후보 도움말

    공정 작업명과 종류로 설비 Asset 범주 후보를 제안합니다. GLB 경로 보유 여부는 카탈로그 경로 기준이며, 브라우저 로딩·기능·제품 적합성을 보증하지 않습니다. 후보를 선택하면 공정 설비 Asset ID와 USD/GLB 입력란에 복사됩니다. 계획에 반영하려면 ‘모델 연결·시간 근거 적용’을 누르세요. 후보는 관계·Flow·애니메이션 승인으로 승격되지 않습니다.

    설비가 보이지 않을 때 · 연결·저장 안내

    03 공정·운송의 ‘설비 후보 연결·저장’은 빈 공정 연결에 카탈로그 시각화 후보를 적용하고 브라우저에 저장합니다. 04 실행의 ‘후보 연결·브라우저 저장·전체 3D 보기’는 같은 처리를 한 뒤 전체 공정 3D를 엽니다. 자동차 예시에서 13개 설비 대상 공정 중 기존 8개 후보와 복합 셀 대표 후보 5개를 포함합니다. 후보 연결은 서버 DB 저장, 전체 설비군 완비, 자동차 적합성 또는 기계 동작 검증이 아닙니다. 서버 DB 저장은 별도 버튼입니다. 기존 연결은 덮어쓰지 않으며, 실행 중에는 연결 작업을 차단합니다.

    설비 카드의 ‘보기’로 개별 설비를 확대하세요. 정적 설비는 표시만 되며 연결을 기계 동작 검증으로 간주하지 않습니다.

    설비와 작업물이 따로 보일 때 · 공정 3D 안내

    실행 화면에서 ‘공정 설비와 모듈 흐름 보기’를 누르면 시간표 순서로 연결된 설비 GLB와 시연 모듈을 같은 공정 작업점 주변에 표시합니다. 작업물은 시연 좌표로 움직이며, 검증된 Port가 없으므로 실제 투입구·기계를 통과한다고 의미하지 않습니다.

    ‘설비 GLB 미연결 · 작업점’ 표식은 위치 안내일 뿐 실제 설비 모델이 아닙니다. 설비 형상을 보려면 해당 공정에 Asset/GLB 모델을 연결해야 합니다. 가상 모듈의 형태 변화, 실제 부품·BOM·충돌·기계 가동은 별도 근거 없이는 검증된 것으로 보지 않습니다.
