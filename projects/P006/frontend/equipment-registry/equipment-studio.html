제품 계획과 공정을 먼저 선택해 작업 대상을 지정합니다. 왼쪽 현재 제품 공정 설비 목록은 전체 3D와 같은 모델을 사용하며 설비명과 실제 GLB 썸네일을 표시합니다. 설비 카드를 선택하면 중앙 편집 정보와 오른쪽 3D가 함께 바뀝니다. 계획 연결 모델과 참고 모델은 구분해 표시합니다. 공정 카드를 눌러도 수정 화면으로 이동하거나 설비를 임의 배정하지 않고, 선택한 공정을 AI 자료 조사·설비 제작 요청의 맥락으로 사용합니다. 왼쪽 제품 계획 → 공정 선택 순서로 선택하면 해당 공정의 설비 카드와 썸네일만 표시됩니다. 전체 공정을 선택하면 제품의 전체 설비 목록으로 돌아갑니다. 공통 자산은 참조 목록이며, 검토 전에는 공정이나 계획에 연결하지 않습니다.

검증 기준: 13개 공정 모델·썸네일 표시, 설비명 검색, 선택한 3D 변경, 기존 연결 모델 우선, 계획 원본 보존. 다음 업무: 선택 설비의 제조사·모델 근거를 확인한 뒤 형상과 동작을 개선합니다.
