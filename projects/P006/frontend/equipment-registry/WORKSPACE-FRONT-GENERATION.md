# Production workspace front generation

The production HTML is assembled from `workspace-front.template.html`, the three inline style files, the three inline script files, and `workspace-front.parts.json`. External scripts remain referenced by the template. The generated `production-workspace-front.html` is the file served by the P006 static route.

Run from this directory:

```sh
node build-workspace-front.cjs --build
node build-workspace-front.cjs --check
```

`--check` compares the generated bytes with the current production HTML and prints a SHA-256 digest. A successful check means the parts reproduce the current HTML exactly; it does not run browser or authenticated workflow QA. `--build <path>` can write to a temporary path for a safe dry run. `--init <source.html>` is the one-time extraction command used to split an existing monolithic page into editable parts.

## Source map

| Part | Responsibility |
|---|---|
| `workspace-front.template.html` | Document structure and external asset references |
| `workspace-front-0.css` to `workspace-front-2.css` | Inline page styles, in original order |
| `workspace-front-inline-0.js` to `workspace-front-inline-2.js` | Inline JSON/JavaScript blocks, in original order |
| `workspace-front.parts.json` | Original tag attributes and insertion order |
| `production-workspace-front.html` | Generated deployable page |

Keep external asset versions and script ordering in the template. Do not hand edit generated HTML; edit the relevant part and run `--build`, then `--check`.
