## 근거의 경계
특정 제조사의 생산 BOM이나 실제 생산시간이 아니다. 모든 기본 시간은 FUNCTIONAL_DEMO.
차체 도착155분 → 조립 기준설정5분 → 주요 결합20분 → 전장15분 → 내장20분 → 외장15분 → 검사20분 → 출고5분 = 최종255분.
USD 경로 입력은 존재·제조 기능 검증이 아니다. 현재 자동차 완제품·부품 모델은 연결되지 않았다.
전체 자동차 제조를 검증했다고 표시하지 않는다. 구매/외주 부품의 공급사 내부 공정은 미정의.

## 모델 계약
productModel / part.model / process.equipmentModel:
`usdPath, glbPath, source` (설비에는 assetId 추가).
process.timeSource: 사용자 입력/실측/자료 출처를 자유롭게 기록.
브라우저는 원본 USD를 직접 렌더링하지 않는다. 같은 서버의 대응 GLB만 표시.
원본 USD/GLB를 생성·변형하지 않는다. 모델의 전체 전시 위치만 별도 Group에서 조정한다.
3D는 공장별 개략 전시 공간이다. 실제 설치좌표/이송경로/조립 Anchor는 미구현.
부품은 준비완료 후 표시, 운송시간 동안 개략 이동, 결합완료 후 숨김.
완제품은 최종 조립완료 후 표시. 가동부 기계 동작은 임의 생성하지 않는다.
모듈당 모델1개 표시: 수량은 표·진행설명으로 확인. 수량별 개별3D Instance는 미구현.

## Asset Registry 연결 Pilot · 2026-09-25
공개 Asset Registry(724 entries) 및 3D manifest(724 GLB records)를 화면에서 읽고, 공정 Asset ID 입력 시 USD source와 GLB path를 자동 채운다. 제품/부품 경로는 개별 입력 가능.
기존 카탈로그에서 시각화 후보로 연결하는 선택 버튼: N076 차체 패널 성형, E148 차체 접합, E121 구동 모듈 제작, E053 구동 모듈 검사, A195 전장 모듈 조립. 모든 단계는 자동차 공정 적합성 미검증이며 선택 후 사용자가 적용한다.
완제품·자동차 주요 부품 모델은 확인되지 않아 허위 조립 형상을 만들지 않는다. 3D 실행 시 주황색 링은 해당 공정 설비의 위치 강조이며 실제 설비 가동 애니메이션이 아니다. USD는 원본 경로 참조이고 브라우저 미리보기는 서버 GLB다.

제품 첫 단계의 모델 현황표는 완제품 1개, 등록된 주요 부품, 설비 후보 5개와 범용 구동 자산 참고 2개를 한 화면에서 보여준다. 모델 확보 목록 CSV를 내려받을 수 있다. 입력 경로의 파일 실재 여부와 카탈로그 등록 여부를 혼동하지 않으며, 자동차 공정 적합성은 미검증으로 남긴다. 724개 자산 원장/카탈로그 대조에서 차량 완제품·주요 부품 제품 모델은 확인되지 않았다. E240/E245는 범용 서보 모터·감속기이며 완성차 구동 모듈로 승인하거나 자동 연결하지 않는다.

## FUNCTIONAL_DEMO 3D 모듈 조립 Pilot · 2026-09-26

- 자동차 계획에서만 사용할 가상 3D 데모 생성기 `product-planner-car-demo.js`를 추가했다. 12개 주요 모듈 그룹을 Three.js 기본 Geometry로 생성하며 휠 모듈은 4개 휠(총 계획수량 15개)을 포함한다.
- 모듈은 해당 일정의 생산/입고 완료 전에는 숨김, 운송 구간에는 출발·도착 공장 양쪽 카메라에 노출하며 공장 위치 사이를 이동, 각 `joinProcessId` 결합 작업 동안 조립 위치로 이동한다. 실행 완료 시간에는 계획된 결합 형상을 이룬다.
- `실행 검토`에서 `전체 공정 애니메이션 재생`을 한 번 누르면 3D 모듈·부지 카메라 준비부터 0분 시작, 전체 종료까지 이어진다. `일정만 실행`은 2D 흐름만 실행한다. 부지 카메라와 메인 카메라는 같은 시뮬레이션 시간을 표시한다.
- 명시 상태: `FUNCTIONAL_DEMO`; 실제 완성차/부품 USD·GLB가 아니고 치수·차종·BOM·실제 물리 결합·생산 적합성을 증명하지 않는다. 실제 연결 GLB가 있다면 가상 모듈과 함께 별도 표시한다.
- 생산·운송·결합 시간은 기존 편집 가능한 일정값을 그대로 사용한다. 계획·관계·Production DB 데이터는 데모 실행만으로 변경하지 않는다.
- 배포·브라우저 시각검수·실제 작업 시간 기록은 `PRODUCT-PLANNER-CAR-DEMO-3D.md` QA 로그를 참고한다.

## RC Car USD Mesh 기반 구조 검토 3D 시연 · 2026-09-26

- `product-planner-rc-car-assembly.html`은 OpenUSD에서 추출한 실제 36 Mesh/1,762,662 points/587,554 triangles를 GLB로 로드한다. USD world transform과 stage 단위 0.01 m/unit을 적용하고, 원본 source mesh/point/triangle 수를 일치시킨다.
- 여섯 구조 항목을 분리 이동해 보거나, 4개 검토 단계에서 구성 그룹을 원래 USD 위치로 순차 이동하는 사용자 설정 시연을 제공한다. 일시정지·계속·초기화·그룹당 시연 시간 설정이 있다.
- 표시 이동은 형상 배치용 translation이다. 실제 joint/체결·제조 순서·가동 동작·작업시간을 의미하지 않으며, 원본 USD의 joint/time animation은 0/0이다.
- 모델은 명시 버튼을 눌렀을 때만 다운로드하며, 제품 계획/Asset Registry/DB에 등록하거나 저장하지 않는다. P006 정적 파생 GLB 28,241,700 bytes 및 MIT License를 공개 경로에 보관한다.
