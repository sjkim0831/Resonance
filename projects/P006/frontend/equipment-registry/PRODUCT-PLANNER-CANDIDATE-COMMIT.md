# Product Planner 설비 후보 적용 및 전체보기 복구

일자: 2026-09-28  
범위: 자동차 시연 계획의 설비 후보 13개 공정 표시·브라우저 저장·전체 공정 3D  
분류: `CATALOG_VISUALIZATION_CANDIDATE` — 실제 자동차 생산 적합성 승인 아님

## 원씽과 사용자 흐름

실행 단계에서 `후보 연결·브라우저 저장·전체 3D 보기`를 한 번 누르면 카탈로그를 확인하고, 빈 설비 연결에 대표 표시 후보를 반영하고, 브라우저 저장 후 GLTFLoader로 전체 3D 화면을 연다. 기존 연결은 덮어쓰지 않는다. 현재 재생 중이면 실행을 변경하지 않고 연결 작업을 거부한다.

공정별 수동 후보 적용은 `모델 연결·시간 근거 적용`, 실행 단계의 후보 연결은 브라우저 로컬 저장을 사용한다. 서버 DB는 별도 `생산 설계 DB 저장` 버튼이 필요하다. 서버 DB 저장 성공이나 새로고침 복원을 실제 검증하지 않았다.

## 후보 맵

기존 8개 카탈로그 후보는 유지한다. 미배정 복합 셀에는 이름과 GLB 경로가 실제 카탈로그에서 확인된 대표 시각화 후보를 추가한다.

| 공정 | 대표 후보 | 추가 설비군 참고 | 제한 |
|---|---|---|---|
| 섀시 모듈 제작 | E121 머시닝센터 | E135, E148, E123 | 공정/BOM 미정, 복합 설비군 전체 아님 |
| 차체 투입·조립 기준 설정 | E148 스폿 용접기 | A123, N143 | 지그·접합점 근거 미확인 |
| 차체·섀시·구동·배터리 결합 | A042 오버헤드 호이스트 | E032, E122 | 위치결정·체결 사양 미확인 |
| 내장·조종석·유리 장착 | E032 작업대·버퍼 | E146, N143, A203 | 유리/내장 공법 미확인 |
| 외장·등화·휠 장착 | A203 자동 부품 키팅 셀 | E032, E122, A042 | 리프트·토크·체결 사양 미확인 |

대표 후보는 3D 한 모델 참조다. 추가 후보는 복합 공정 카드의 읽기 전용 후보 미리보기에서 별도로 확인한다. 후보 연결이 전체 설비군 배치, 차량 호환, 직접 연결, Flow 또는 기계 Animation을 의미하지 않는다.

## 저장·복원·표시 계약

- Candidate helper는 `Asset Registry`와 3D manifest를 읽고 같은 Asset의 USD/GLB 경로를 사용한다.
- 현재 process model에 값이 없으면 후보 모델을 추가한다.
- 같은 Asset ID이고 USD/GLB가 빠진 경우에만 누락 경로를 보완한다.
- 기존에 다른 Asset/경로가 있으면 보존하고 후보로 덮어쓰지 않는다.
- 계획 적용은 owning Product Planner의 revision 검사를 통과해야 하며 `changed()`를 통해 브라우저 localStorage에 저장한다.
- 3D 모델 파싱 실패는 `GLB 로딩 실패`로 남기며, 미배정·누락 모델은 공정 작업점 표시를 유지한다.
- 작업물 Proxy, 제품/BOM, Flow/relationship, USD/GLB 원본은 변경하지 않는다.

## 실제 확인과 한계

- 현재 서버 Asset Registry에서 E121/E148/A042/E032/A203 각각의 Asset ID와 GLB manifest 경로를 확인했다.
- 서버 배포 후 브라우저 3D 전체 로드, 13개 자산 파싱, 5개 복합 후보 매핑, 저장 계획 복원, 애니메이션 재생은 이 기록 작성 시점에 아직 실제 브라우저에서 실행하지 않았다. 따라서 완료 수치를 PASS로 표기하지 않는다.
- 사용자는 계획에서 버튼 실행 후 `설비 GLB 경로 13/13`, `실제 GLB x/y`, 실패 수, 각 카드의 대표 후보 경고를 확인한다. GLB 파싱 오류는 실패 수로 보존한다.
- 작업 소요 시간은 실제 command/browser 작업 종료 시 기록한다. 추가 용량: 코드/문서 외에 후보 GLB 생성 0개.

## 업무 경계

원씽: 13개 공정이 더는 이유 없이 미배정으로 남지 않도록 시각 후보와 미검증 경계를 명확히 드러내고 실제 3D 전체보기를 연결한다.

깨달음: Asset/GLB가 등록되어 있다는 사실은 공정 장비로 적합하다는 증거가 아니다. “화면에 모델을 띄우는 후보 연결”과 “생산 설비 승인”은 다른 Gate다.

다음 업무 카드: 대표 설비와 나머지 설비군을 공정별 BOM·작업물 치수·필요 동작·지그·기능 근거로 검토하고, 실제 계획 적용/브라우저 복원/전체 3D/재생을 한 공정 셀에서 확인한다. server DB 저장·동기화·전체 255분 실행은 별도 검증한다.
