# P006 전체 공장 USD 저장

2026-09-23. 기존 Composer 배치와 Stage 생성기를 재사용한다.

## 사용 절차

1. 공장 레이아웃을 열고 설비·벽·통로 배치를 확인한다.
2. 상단 `전체 공장 USD 저장`을 누른다. 현재 화면을 DB에 저장한 후 해당 저장 버전 전체를 내보낸다.
3. 생성·검증 완료 시 `Factory.usdz 다운로드`를 누른다.
4. Omniverse File → Open에서 USDZ를 연다. 패키지에 원본 애니메이션이 있을 때 타임라인을 재생한다.

미저장 화면은 DB 저장에 성공한 경우에만 내보낸다. 저장 실패·버전 충돌은 화면에 표시한다. 원본 자산 Geometry와 관계 검증 상태는 변경하지 않는다.

## 요구사항과 구현 매핑

| 요구사항 | 구현 | 검증 |
|---|---|---|
| 전체 공장 한 파일 | `/composer/stages`의 `portable:true`, `factory_portable_exporter.py` | USDZ 재오픈, 전체 객체 수 |
| 위치·회전·Scale 보존 | 기존 stage_exporter의 좌표 계약·인스턴스 매핑 재사용 | 개별 Transform 독립 계산 및 패키지 전후 비교 |
| 벽·바닥·통로 포함 | 기존 파라미터 건축 형상 생성 | QA 설비 3 + 건축 3 = 6개 |
| 다른 PC로 이동 | Stage flatten 후 참조 이미지/자료를 USDZ에 수집 | 외부 참조·미해결 참조 0, 다운로드 ZIP 바이트 확인 |
| 원본 애니메이션 보존 | 시간 샘플·값·범위·시간 단위를 패키지 전후 비교 | 별도 시험용 121 샘플 보존 PASS |
| 현재 화면 저장 후 내보내기 | `factory-usd-export.js`: save → export → poll → download | 미저장 3개 건축 객체 포함 확인 |

전체 배치·내보내기 데이터는 기존 API 권한을 따른다. 새 공개 다운로드나 임의 세션은 만들지 않는다. 패키지 검증 PASS 전에는 파일 다운로드가 차단된다.

## 애니메이션 범위

기존 원본 USD에 기록된 시간 샘플을 보존한다. 웹 JavaScript의 Flow 상태·작업물 이동을 새 USD 애니메이션으로 자동 변환하지 않는다. 시간 샘플 존재와 실제 기계 동작 검증은 구분한다. `newAnimationAuthored=0`, `browserFlowBaked=false`를 보고서에 기록한다.

요청 Layout `ebd63f43-0146-4173-9a66-ab09b67a438c`의 DB v1은 E053/E122/A203 설비 3개다. 원본 시간 샘플은 0개였다. 첨부 화면의 12개 객체는 미저장 화면이므로 이 DB v1 산출물에는 포함되지 않았다. 새 버튼을 사용하면 그 시점 화면의 변경사항을 먼저 저장한다.

## 실제 QA

- 요청 DB v1: 객체 3, 설비 3, 건축 0, USDZ 200805 bytes, 미해결 참조 0. Stage 생성·패키지 검증 0.103초.
- 요청 파일 Omniverse Kit headless: PASS, composition errors 0, 1280×800 렌더 캡처. Kit 스크립트 검증 2.148초. 사용자 GUI 조작 검수는 별도다.
- Kit 검수 세션은 캡처 이후 종료 요청만으로 즉시 끝나지 않아 150초 제한에서 종료됐다. 파일 열기·렌더 성공과 애플리케이션 정상 종료는 별개이며 정상 종료 PASS로 기록하지 않는다.
- 독립 QA Layout `dc92362c-e244-466e-90d5-ad036f82c8ec`: 브라우저 건축 카드 더블클릭으로 바닥·벽·통로 3개 추가 → 전체 USD 버튼 → 자동 DB 저장 v2 → 총 6개 USDZ 다운로드 PASS. 원래 요청 Layout v1 유지.
- 시험용 애니메이션: 0~120의 121개 회전 샘플 보존. 실제 제품 애니메이션 검증 자료로 사용하지 않는다.

## 다음 업무

웹 공정 애니메이션을 포함하려면 원본 USD Prim과 웹 가동부 Node 매핑, 승인된 피벗·축·시간축, 작업물 경로를 먼저 확정하고 별도 애니메이션 레이어로 기록해야 한다. 현재 파일의 정적 형상을 새 기계 동작 검증으로 승격하지 않는다.

신규 유료 API 및 자산 구매 0건. 추가 출력 용량은 각 보고서 `bytes`를 사용한다.
