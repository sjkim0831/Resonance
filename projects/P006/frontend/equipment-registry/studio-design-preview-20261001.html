설비 제작 전체 단계

각 단계의 입력, 진행, 결과, 검토와 저장 지점을 한눈에 확인합니다.
5단계 모두 표시
01 · 참고자료 수집기준 자료

제조사·모델, 사진, 매뉴얼, 도면, 영상, CAD / USD / GLB를 출처와 함께 모읍니다.

결과
출처 링크 · 자료 유형 · 확인 사실 · 신뢰/검토 상태 · 중복 여부
02 · 3D 시안 5개비교·선택

근거 자료에 맞춘 형상 방향을 다섯 가지로 제안하고 차이점을 비교합니다.

${[1,2,3,4,5].map(n=>`
시안 ${n}이미지 · 비교점
`).join('')}
결과
시안 이미지 5개 · 출처와의 일치 항목 · 차이·가정 · 검토 의견
03 · 3D 자산 제작USD / GLB

선택한 시안을 검토용 자산으로 제작하고 단위·축·크기·모델 구조를 확인합니다.

입력
선택 시안 · 치수 근거 · 좌표계 · 원본 자산 버전
결과
USD 원본 · GLB 미리보기 · 썸네일 · 변환/검증 로그 · 품질 지표
04 · 가동 정보 수집동작 근거화

움직이는 부품과 동작값을 자료에 연결합니다. 불명확한 값은 추정 또는 미확인으로 표시합니다.

결과
동작 단계 · 가동부 · 축/방향 · 거리/속도/시간 · 작업 순서 · 출처 · 확인 상태
05 · 애니메이션 제작·반영검토 후 적용

4단계에서 확인한 가동부와 동작값으로 애니메이션을 만들고 검토한 뒤 공정에 연결합니다.

입력
검토 승인된 USD / GLB · 동작 단계 · 축 · 거리 · 속도 · 근거
결과
애니메이션 파일 · 재생 미리보기 · 단계별 시간 · 오류/검증 결과 · 버전
화면 설계도움말 · 업무 길잡이QA · 전체 업무 · 다음 작업
설계와 기능 보존 목록

목적: 기존 기능을 삭제하지 않고 선택 / 편집 / 검토 / 실행 결과의 4영역으로 통합합니다. 공통 색상·간격·폼·탭을 CSS 토큰으로 재사용합니다. KRDS 적합성 인증 또는 전체 접근성 검증을 완료한 화면은 아닙니다.

기능 위치: 제품·공정 선택 → 상단 / 설비 검색·신규·카탈로그 → 왼쪽 / 제조사·모델·치수 → 기본 정보 / 업로드·누적 출처·수동 삭제 → 참고자료 / 시안 5개·USD·GLB → 3D 제작 / 가동부·축·방향·거리·속도·소요 시간·작업 순서·근거 수집 → 4단계 / 검토 승인 자산·애니메이션 제작·재생·검증·공정 적용 → 5단계 / 적용 범위·승인 → 공정 연결 / 미리보기·품질 → 오른쪽 / 진행·결과·오류·재시도·이력 → 하단.

검수 항목: 1) 참고자료 수집과 출처 검토 2) 3D 시안 5개와 선택 3) USD / GLB 생성과 미리보기 4) 가동부·축·방향·거리·속도·시간·작업순서·근거 5) 애니메이션 생성·재생·검증·공정 반영. 현재는 디자인 시안이며 실제 AI·저장·파일 생성은 연결되지 않았습니다.
