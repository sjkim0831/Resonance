1. 업무 흐름

설비 인스턴스 선택증거 GLB 등록카탈로그 원본과 좌·우 비교설치·작업 위치 JSON 보존저장 계획의 공정에 초안 적용Product Planner 3D 확인

등록된 증거 파일은 검토 전 상태입니다. 수정 파일은 공통 카탈로그 자산과 분리 보관하고 기존 모델·승인 상태를 승격하거나 덮어쓰지 않습니다.

3. 공정 초안 데이터

Product Planner의 p006-product-plans-v1 저장 계획 중 선택한 공정에 다음을 기록하고 revision을 증가시킵니다.

equipment instance ID·이름비공개 evidence GLB 경로evidence ID·SHA-256installation JSONworkpiece / anchor JSONUNREVIEWED_DRAFT

저장은 현재 브라우저의 Product Planner localStorage입니다. 설치·작업 Anchor는 공정 모델 레코드에 같이 전달되는 참조 데이터입니다. 각 설비의 동작 Clip이나 실제 조립 경로에서 이 기준점을 소비하는지는 별도 기능 검증 항목입니다.

4. 안전·호환 규칙

  • 허용 모델 주소는 같은 출처의 카탈로그 .glb 또는 P006 registry API의 evidence ID 경로뿐입니다.
  • 수정 GLB 파일당 5 MiB 업로드 제한을 따릅니다.
  • 외부 출처 주소·임의 파일 경로는 공정 뷰어에서 거부합니다.
  • 초안은 공정 화면에서 표시 가능한 연결 후보이며, 실물 동일성·설치·Port·동작·공정 적합성 승인이 아닙니다.
  • 원본 USD/GLB 및 카탈로그 파일은 변경하지 않습니다.

5. Pilot QA 현황

확인 정적 파일 6개 HTTP 200 · JavaScript 구문 검사 2/2 · 비교 버튼 DOM 1개 · 페이지 JavaScript 예외 0건 · 실제 페이지 캡처 완료.

실파일 검증 미완료 검수 브라우저에서 설비 레지스트리 레코드를 받을 수 없어 실제 evidence GLB 업로드, 저장/새로고침 복원, 원본-수정본 렌더링 비교, 저장 공정 적용 후 모델 로딩은 아직 측정하지 않았습니다.

기계 판독 결과와 실제 캡처는 작업 산출물 폴더의 equipment-studio-revision-qa.json, equipment-studio-revision-qa.png에 함께 보관됩니다. 이 정적 웹 경로는 JSON 파일을 직접 서빙하지 않습니다.

6. 재현 절차와 다음 업무

  1. 설비 스튜디오에서 실제 설비 인스턴스를 선택합니다.
  2. Asset ID에 실제 원본 모델을 입력해 먼저 불러옵니다.
  3. 별도 수정 GLB를 GEOMETRY 증거로 등록하고 새로고침해 증거 ID/SHA 복원을 확인합니다.
  4. 원본과 비교를 눌러 화면·Mesh·Triangle·Material·Animation 수를 기록합니다.
  5. 설치·작업 위치 JSON을 저장한 뒤 대상 저장 계획/공정에 초안 적용합니다.
  6. 같은 브라우저에서 Product Planner 3D를 열어 초안 표시·설비 이름·미검토 상태·로딩 오류를 확인합니다.
