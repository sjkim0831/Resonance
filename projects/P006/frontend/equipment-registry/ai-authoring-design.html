설비 AI 조사 · 설계와 업무 길잡이

설계 버전: 2026-09-30 · 원씽: 선택한 설비의 실제 조사 결과와 출처를 서버에 저장하고 검토할 수 있게 한다.

현재 1번 참고자료 수집과 4번 가동 정보 수집이 연결됩니다. 서버 키 설정과 모델 접근 권한이 필요합니다. 시안 이미지·USD·애니메이션 제작은 후속 작업입니다.

전체 업무와 절차

  1. 로그인한 사용자가 설비 목록에서 대상 자산을 선택합니다. 작업 대상 이름·자산 ID·제품 공정을 확인합니다.
  2. 참고자료 수집 시작을 누르면 서버가 작업 ID를 발급합니다. GPT-6.1 Sol이 웹 검색을 수행합니다.
  3. 화면은 3초 간격으로 상태를 확인합니다. 완료 시 보고서와 출처 링크를 표시하고 자료 목록을 갱신합니다.
  4. 사용자는 제조사·모델 일치 여부와 치수 근거를 검토합니다. 조사 결과는 미검토 자료로 저장됩니다.
  5. 가동 정보 수집으로 축·방향·거리·속도·작업 순서를 조사합니다. 이후 시안·모델 제작에 연결합니다.

관리자 키 설정

서버 터미널에서 아래 명령을 실행하고 새 키를 비표시 입력합니다. 키는 웹 폴더 밖에 권한 600으로 저장하며 브라우저로 전송하지 않습니다.

sudo python3 /opt/Resonance/projects/P006/runtime/equipment-registry/configure-openai-key.py

입력 후 화면의 ‘연결 상태 확인’을 누릅니다. 서비스 재시작은 필요 없습니다.

가격

공식 공개 가격 기준 입력 100만 토큰 $2, 출력 100만 토큰 $10. 예: 입력 5,000 + 출력 3,000토큰이면 $0.04이며 웹 검색 비용은 별도입니다. 실제 청구액은 OpenAI 사용량에서 확인합니다. 모델·가격 근거

QA 검증 범위

자동 테스트: 키 미설정, API 401, 정상 응답의 보고서·출처 저장, 중복 요청, 계정 간 접근 차단, 서버 중단 복구, 미구현 단계 차단. 정상 생성 테스트는 가짜 API 응답으로 실행하며 실제 OpenAI 성공 검증은 새 키 설정 후 별도 기록합니다.
