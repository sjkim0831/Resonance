생산망 높이·장소 수 변경

실행 화면

사용 순서

  1. 실행 탭에서 전체 생산망 선택. 기본 높이 900px, 720/900/1200px 변경 가능.
  2. 부지·공장 탭에서 추가·삭제와 위치·크기 수정.
  3. 입력 검증·배치 반영 후 반영된 부지·공장 수 확인.
  4. 부지별/공장별 카메라 선택. 6개 초과 시 다음 카메라로 확인.
  5. 검토 후 브라우저 저장 또는 JSON 내보내기.

설계·QA·전체 업무

높이는 주 카메라만 변경하며 개별 카메라를 없애지 않습니다. 카메라 수·페이지·선택 목록은 반영된 계획에서 계산합니다. 하위 장소·운송이 연결된 삭제는 차단합니다. 입력 변경은 반영 전까지 기존 3D를 유지합니다.

자동 검사 범위: 높이 900/1200, 부지 3→8→2, 공장 3→16→2, 카메라 페이지 이동, 선택 목록 갱신, 단일 WebGL 유지. 운영 데이터와 독립된 브라우저에서 검사합니다.

다음 업무

실제 부지·공장 개수 및 위치 입력 후 JSON 저장. 실제 모델 연결과 운영 서버 저장은 별도 작업입니다.
