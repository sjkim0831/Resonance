부지 시각 개선 v2

실행 화면 · 좌표·시간·저장 설계

구현

  1. 부지 두께·경계 울타리·출입구·관리 부스와 공장 벽·창·기둥
  2. 공장 앞 입고(파랑)·대기(황색)·출고(초록)와 구획선
  3. 입력 운송 경로의 바닥 띠·방향 화살표
  4. 고정 글자 크기의 화면 라벨, 겹침 억제 및 줄바꿈 방지
  5. 전체 460px·개별 290px 뷰, 선택 경계 밖 클리핑
  6. 단일 렌더러·장면 공유, 계산·경로·저장 스키마 유지

해석과 한계

새 시설은 참고용 자동 배치입니다. 실제 현장 도면, 출입구와 운송 경로 연결, 안전 통로, 차량 회전반경, 장애물 회피를 검증하지 않았습니다. 자동 물류 구역이 부지 밖으로 나가면 표시하지 않습니다. 운송 계산은 기존 접점·경유점을 그대로 사용합니다. 실물 설비 모델은 아직 미연결입니다.

검증 절차

계산 단위 테스트 9개와 독립 브라우저 시나리오 11개를 재실행합니다. 액터는 테스트 전용 비로그인 브라우저이며 운영 데이터 쓰기나 AI 호출을 하지 않습니다.

좌표·방향 변경 → 배치 반영 → 저장·복원 → 거리·시간 계산 → 재생·정지 → 종료 위치 → 개별 카메라 전환 → 부지 추가 → 모바일 검증 순서입니다. 시각 검수는 전체 및 개별 화면의 외부 부지 혼입, 라벨 줄바꿈, 영역 구분을 확인합니다.
