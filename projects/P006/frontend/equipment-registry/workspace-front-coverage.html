6. 운송 연결 자동 동기화 · QA 2026-10-04

공정의 출발/도착 공정을 변경하거나 해당 공정 설비를 다른 공장으로 옮기면 운송 공장과 부지 연결을 즉시 갱신한다. 공장 좌표가 변하면 자동 경로·거리를 다시 계산하며 수동 거리/시간은 그대로 둔다.

검증: node qa-transport-auto-sync.cjs · 7/7 PASS · 브라우저 JS 오류 0. 실브라우저에서 발견한 이벤트 순서 결함은 캡처 단계에서 상태 변경을 처리해 렌더 전에 동기화하는 방식으로 수정했다. 캡처: transport-auto-sync-qa.png. 테스트 변경은 QA 사본 전용이며 서버 계획은 저장하지 않았다.

다음 확인은 실제 부지 출입구, 도로, 차량 회전반경·폭을 입력해 생산/물류 담당자가 이동 가능성을 승인하는 것이다. 시연 경로 계산만으로 현장 적합성을 보증하지 않는다.

7. 순서형 생산 흐름 워크벤치 · QA 2026-10-04

입력 메뉴를 6단계로 정렬했다: 제품·품목 → 공정 흐름 → 부지·배치 → 설비 스튜디오 → 실행·3D → 검토·저장. 공정 흐름 보드는 공정별 투입품·산출품·부산물, 담당 설비·공장·부지·셀, 선행관계와 시간 범위를 보여주며, 공정 사이 운송에는 품목·수량·차량·출입구 경로와 상하차/주행 시간을 함께 배치한다.

검증: node qa-transport-auto-sync.cjs · 14개 확인 PASS · 브라우저 JS 오류 0 · 인라인 JS 문법 PASS. 단계 편집/운송 편집 연결과 도움말 단계 순서를 포함해 검사했다. 캡처: production-journey-qa.png, production-journey-transport-qa.png. 테스트는 QA 복사본만 변경했으며 실제 계획 서버 저장/복원은 실행하지 않았다.

이 보드는 현재 연결된 계획 데이터를 읽어 보여주는 검토 UI다. 썸네일/GLB 경로는 실제 제조사 모델, 제품 변형, 물리 동작 또는 현장 운송 안전성을 승인하지 않는다. 그런 검증과 실계정 저장/복원은 다음 단계다.
