# 전체 설비 이름표 표시 수정 — 2026-09-28

## 설계와 원인
전체 보기에서도 focusedEquipmentId와 일치하는 1개만 이름표를 표시하던 조건을 제거했다. 전체 보기에는 모든 로드된 설비의 이름표, 개별 설비 보기에는 선택 설비의 상세 이름표를 표시한다. 자동 공정 추적은 기본 OFF이며 사용자가 켤 수 있다.

카메라 맞춤 계산은 원본 모델 Bounds를 세계 좌표로 변환해 사용한다. 이름표 Sprite 크기가 카메라 거리를 확대하는 피드백을 제거했다. 부지별 카메라에도 동일 원칙을 적용했다. 모델 크기, 공정 배정, 저장 데이터, 관계 승인 상태는 변경하지 않는다.

## 도움말 / 업무 길잡이
1. 공정 설비와 모듈 흐름 보기로 모델을 로드한다.
2. 전체 배치 보기에서 전체 설비 이름표를 확인한다.
3. 공정 카드의 설비 보기로 개별 설비와 작업물을 확대한다.
4. 현재 공정 셀 따라가기를 선택할 때만 자동 추적한다.

## QA
- JavaScript 구문 검사 2개 파일 PASS.
- 서버 배포 후 실제 브라우저 GLB 로드 13/13, 실패 0.
- 완료 상태 전체 보기: 3+4+6개 이름표가 표시된 화면 캡처 확인.
- 자동 추적 기본 OFF 확인.
- 좁은 화면/회전 각도에서는 이름표가 겹칠 수 있음. 전체 이름표 충돌 회피는 미구현.
- 이번 수정에서 시작/중간 시점의 전체 재생 회귀와 DB 저장 검증은 수행하지 않음.

## 다음 업무 카드
이름표 화면 좌표 충돌 회피 및 선택 설비 상세 패널 분리. 목표: 회전/좁은 화면에서도 이름표와 실제 모델을 가리지 않도록 배치.

설비 표시 성공은 자동차 공정 적합성 또는 기계 동작 검증을 뜻하지 않는다. 기존 FUNCTIONAL_DEMO 경계를 유지한다.
