# 설비 등록·공통 3D 연결 프로세스 검증

사용 계정: 기존 P006 프로젝트 관리자. 새 계정 생성/권한 임의 부여 0.

1. 기존 계정 인증 → 724 자산 / 666 Entry / 16 Equipment Type 확인.
2. QA 전용 업체 A/B → 공장 → 라인 → 공정 등록.
3. 용해로 종류 실제 설비 형식 입력(가상 검수 데이터) → E005 REFERENCE 추천.
4. 기준 표현 한계 명시 수용 → 연결 상태/업체 연결률 갱신.
5. 새로고침 → 동일 등록/연결 복원.
6. 이미지 확대 → 닫기 → 잔류 이미지 없음.
7. 검수 자료 업로드 → UNREVIEWED → 인증 다운로드.
8. 관리번호 수정 → 저장/재조회, 연결 수용 해제/재검토.
9. JSON 2행 검사 → 미저장 확인 → 확정 등록 → NO_MATCH/BLOCKED 분리.
10. 업체 B의 설비도 같은 E005 참조 → 공통 자산 복제 없음.
11. 업체 필터/검색 → 소속별 집계 → 모바일 시각 검수.
12. 비로그인 조회/자료 다운로드 401, CSRF 헤더 없는 쓰기 403.
13. QA 전용 업체/설비 UUID만 제거 → 실제 업체 0, 실제 설비 0 복원.

## 결과

API/DB 30/30, 실제 브라우저 23/23. API/DB 0.29초, 브라우저 6.575초. 최초 배포 0.78초(프록시 재시작 포함, 렌더 시간 아님).

API/DB 시험의 승인 자료는 트랜잭션 내부 가상 fixture이며 전량 롤백. EXACT 성공 시험은 규칙 엔진 검증이지 실물 장비 검증이 아니다. 교차 업체 권한은 기존 관리자 로그인 + 역할 축소 테스트 principal로 검증했으며 2개 실사용 계정 로그인을 수행한 것은 아니다. 운영 ASSET_READY/REAL 승격 0.

10,000개 합성 자산을 DB에 임시 삽입 후 50개 페이지 조회 시험, 전량 롤백. 3D 동시 렌더 성능 시험 아님.
