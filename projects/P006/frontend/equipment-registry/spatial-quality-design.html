부지·공장 시각 품질 개선 v3

실행 화면 열기

1. 설계와 구현

전체 생산망과 개별 부지·공장 카메라는 하나의 장면과 WebGL 렌더러를 공유합니다. 부지 확대 버튼으로 상세를 확인합니다. 좌표·방향·거리·운송 시간은 기존 입력과 계산을 유지합니다.

패널 외벽·창·보·조명, 선반·적재물, 작업 셀 프레임, 울타리 기둥·레일, 녹지, 게이트·차단기·횡단보도, 트럭 캐빈·유리·바퀴·트레일러를 추가했습니다. 반복 시설은 재질별 인스턴싱으로 렌더링합니다.

2. 도움말과 한계

부지 확대 → 드래그 회전·휠 확대 → 재생 → 개별 카메라 확인 순서입니다. 시설 상세는 시각화용 예시이며 실제 설비 배정·안전 동선·실측 설계를 뜻하지 않습니다. 사진 수준 렌더링이나 검증된 USD/GLB를 제공하는 단계는 아닙니다. 매우 작은 장소는 시설 상세를 생략합니다.

3. QA 업무

좌표·회전·경계 검증, 거리·시간 계산, JSON 저장·복원, 재생·일시정지·완료, 차량 숨김과 제품 유지, 부지·공장 카메라, 모바일 가로 넘침을 회귀 검사합니다. 부지 확대 캡처에서 글자·시설 표시를 별도 검수합니다.

4. 다음 업무 · 원씽

실제 설비 모델 1개를 셀 좌표에 연결하고 크기·작업점·가동축을 검증합니다. 시각화용 소품과 실제 배정 설비는 구분해서 표시해야 인지 혼동을 막을 수 있습니다.

독립 프로토타입입니다. 운영 계획·AI·권한·서버 저장·녹화는 연결되지 않았습니다. 기존 운영 화면과 데이터를 변경하지 않습니다.
