3D → 설비 스튜디오 → 공정 수정본

통합 화면

1. 사용자 절차

저장한 계획의 3D 설비를 클릭하거나 설비 카드에서 선택 → 우측 ‘설비 수정’ → 스튜디오 상단 선택 공정 확인 → 이름·USD·GLB 경로·자료 근거 수정 → 현재 공정에 수정본 적용 → 3D로 돌아가 수정본 반영.

미저장 계획은 먼저 저장·3D 적용해야 합니다. 미적용 입력이 있으면 이동을 막습니다. 연결된 설비 레코드 ID가 확인되면 기존 스튜디오 레코드를 선택합니다. 없거나 모호하면 임의 레코드를 수정하지 않고 공정별 연결 패널을 제공합니다.

2. 데이터·보존 정책

planId·processId·revision과 카메라 target/radius/theta/phi, 재생 시점을 전달합니다. 현재 공정의 equipmentModel만 변경하고 UNREVIEWED_DRAFT로 기록합니다. 동일 서버 GLB의 응답 및 파일 서명을 확인합니다. 원본 파일을 덮어쓰거나 다른 공정에 자동 전파하지 않습니다. 다른 탭에서 계획 버전이 변경되면 적용을 차단합니다.

USD는 원본 경로 참조이며 내용·실물 대응은 별도 검증입니다. 모델 형상 편집/CAD·USD 자동 생성은 이번 기능이 아닙니다. 실제 자료 업로드·등록 설비 수정은 기존 스튜디오 기능과 권한을 사용합니다. 상단 ‘현재 공정’ 수정과 하단 공통 등록 정보 수정은 범위가 다릅니다.

3. QA·다음 업무

자동 검증 결과 · 선택 화면 · 수정 화면 · 복귀 화면

독립 QA 계획으로 선택→스튜디오 진입→현재 공정 수정→복귀를 검증합니다. 실제 사용자 설비 레코드의 자료 업로드·형상 변경 검수는 별도입니다. 다음 업무: 대표 설비 1개의 실제 수정 GLB와 근거 자료를 등록하여 외형·동작을 비교 검수합니다.

원씽: 공통 원본 보존과 선택 공정만 수정. 비용: 추가 유료 서비스 0원, 기존 인프라 제외.
