2. 검수 기록

  1. 가상 예시/비로그인 → 실행 화면 → GLB 13/13, 실패 0 확인.
  2. 재생 → 시간 0.1분에서 10.3분 진행 → 일시정지 확인.
  3. 시간 막대 끝으로 이동 → 완료 13/13 및 최종 검사 완료 표시 확인.
  4. 개별 카메라 → 공장별 선택 → 공장 3개 이름 출력 확인.
  5. 설비 수정 → N076 스튜디오 연결 → 제조사·모델 입력 및 13개 썸네일 확인.
  6. 초안 저장 → Revision 2 → 새로고침 후 Revision 2 복원 확인.

자동 검사는 test-workspace-front.cjs로 실행합니다. 결과는 workspace-front-test-results.json에 기록됩니다. 기능 원장 115개는 모두 탐색 가능하지만 115개 기능의 구현 완료를 의미하지 않습니다. 인증·권한·서버 저장·전체 프로세스 E2E는 미검증입니다.

3. 생성·복구

workspace-front.template.html + workspace-front.css + workspace-front.js + v9 JSON → build-workspace-front.cjs → 단일 HTML. 기존 페이지는 보존됩니다. 초안은 전용 localStorage 키를 사용하고 참고 파일은 IndexedDB에 저장합니다. JSON에는 로컬 첨부 바이너리가 포함되지 않습니다.
