# 공정별 설비 후보와 부지 카메라 가시성 계약

날짜: 2026-09-27  
범위: Product Planner 공정 후보표와 부지별 3D 카메라의 표시 상태  
상태: UI 반영 코드 작성, 화면/배포 검수 대기

## 사용자 업무 흐름

1. `공정·운송`에서 각 공정의 이름, 공정 종류, 공장/부지를 확인한다.
2. 공정별 설비 후보표에서 작업명 범주와 카탈로그 Asset 후보, 근거를 확인한다.
3. 후보를 선택해 설비 Asset ID/USD/GLB 입력칸에 복사한다.
4. `모델 연결·시간 근거 적용`으로 계획에 반영한다.
5. 실행 검토에서 `부지별 시연 카메라 로딩`을 누른다.
6. 부지 카드의 대상 공정 수, Asset+GLB 연결 수, 3D Scene 로드 수, 미연결 공정명을 확인한다.

후보 입력은 모델 입력칸에만 복사되며 명시적 적용 전에는 계획을 확정하지 않는다. 후보·GLB 경로가 연결되어도 자동차 제조 적합성, 실제 물리적 연결, 설비 Animation을 승인하지 않는다.

## 후보 표 데이터 규칙

- 설비 대상 공정은 `DISPATCH`를 제외한 전체 공정을 표시한다.
- 현재 지정 후보 8/13: `body-form→N076`, `body-weld→E148`, `body-paint→N088`, `drive-make→E121`, `drive-check→E053`, `chassis-check→E123`, `systems-join→A195`, `final-check→E053`.
- 후보 근거는 현재 Asset Registry 이름/범주 및 GLB manifest의 경로다. 후보는 미적용으로 남고 사용자가 선택해야 한다.
- 미지정 후보 5/13: `chassis-make`, `body-join`, `chassis-join`, `trim-join`, `finish-join`. 각 공정은 수행 방식/작업물/전용 설비 요구 근거가 부족하므로 임의 배정하지 않는다.
- N088은 분체 도장 부스이므로 자동차 차체 도장과의 호환성을 가정하지 않는다. E123은 치수 측정 후보이지 기능/주행 검사 설비가 아니다. E053은 검사 작업대이며 완성차 시험 설비로 간주하지 않는다. A195는 하니스 조립 후보로서 열관리 통합을 수행한다고 간주하지 않는다.
- 후보 등록은 Relationship 상태, `DIRECT_VERIFIED`, `FLOW_ELIGIBLE`, `ANIMATION_VERIFIED`를 수정하지 않는다.

## 부지 카메라 상태

부지 카드의 계산 기준은 해당 부지에 속한 공장의 비출고 공정이다.

```text
설비 대상 수      = 해당 부지 공정 중 kind != DISPATCH
Asset+GLB 연결 수 = equipmentModel.assetId와 equipmentModel.glbPath가 모두 존재
3D Scene 로드 수  = 현재 viewer.entries에서 해당 공정 ID에 대응하는 설비 Scene 수
미연결 공정명     = GLB 경로가 없는 대상 공정의 이름
```

`3D Scene 로드`는 렌더 성공/기능 적합성의 인증이 아니다. 로딩 실패는 카메라 렌더 결과/기존 모델 오류 현황에서 별도 확인해야 한다. 카메라 프레임은 현재 렌더 대상의 실제 bounds로 산정되며 설비가 할당되지 않은 공정은 화면에 나타나지 않는 게 정상이다.

## 안전 경계와 다음 업무 카드

- 기존 계획 및 저장된 DB 데이터는 자동 변환하지 않는다.
- 모든 후보 모델은 실제 GLTFLoader Scene, bounds, 제품 호환성, 기계 가동 근거를 개별 검토하기 전까지 후보 상태다.
- 카메라 로딩 때 상세 모델 로더의 최신 후보 계획을 다부지 카메라 집계에도 즉시 전달한다. 후보 8개 GLTFLoader 성공과 3개 부지 3D Canvas 표시를 확인했다.
- 다음: 미배정 5개 공정의 설비 요구조건을 정의하고 후보를 찾는다. 현재 연결된 모델은 자동차 제품 적합성과 기계 애니메이션이 검증되지 않았으므로 실제 생산 애니메이션으로 간주하지 않는다.

## 후보 일괄 입력 시 기존 연결 보존

`자동차 모듈 설비 후보 연결`은 후보가 등록된 공정 중 Asset ID 또는 GLB 경로가 이미 입력된 항목은 건너뛴다. 기존 연결을 보존하고 빈 공정에만 후보를 임시 입력한다. 화면 결과에는 `후보 추가`와 `기존 설비 연결 보존` 개수를 따로 표시하며, 입력은 `모델 연결·시간 근거 적용`을 누르기 전까지 편집 화면의 후보 상태다. 후보 적용 후에도 자동차 공정 적합성 및 기계 동작은 승인되지 않는다.

## 복합 공정 셀의 설비군 참고 · 2026-09-27

- 미배정 5개 공정 행에 필요한 설비군, 카탈로그에서 GLB가 있는 참고 자산, 미확인 근거를 표시한다.
- `chassis-make`: 가공·성형 + 접합 + 치수검사 복합 셀. 예시 참조 `E121`, `E135`, `E148`, `E123`.
- `body-join`: 차체 고정 지그 + 용접/접합 셀. 예시 참조 `E148`, `A123`, `N143`.
- `chassis-join`: 위치결정/리프트 + 조립 지그 + 체결 셀. 예시 참조 `A042`, `E032`, `E122`.
- `trim-join`: 내장·유리 핸들링 + 조립 지그/접착 공정. 예시 참조 `E032`, `E146`, `N143`, `A203`.
- `finish-join`: 외장·등화·휠 키팅 + 위치결정/장착 셀. 예시 참조 `A203`, `E032`, `E122`, `A042`.
- 위 Asset은 이름/카테고리와 GLB 경로를 기준으로 한 시각 참고 후보다. 차종 적합성, 가동범위, 작업물 규격, 셀 완결성을 의미하지 않으며 자동으로 계획에 할당하지 않는다.
