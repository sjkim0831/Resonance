1. 범위와 완료 기준

2026-10-01. 기존 운영 계획을 변경하지 않는 독립 기능 검증 화면입니다. 제품·설비 스튜디오·AI 등 기존 통합 시안은 유지하며, 위치·운송만 실제 계산과 단순 3D에 연결했습니다. 전체 운영 기능 통합 완료를 의미하지 않습니다.

원씽: 유효한 위치·방향·경로·시간이 하나의 모델에서 계산되고 동일 장면의 모든 카메라와 재생 위치에 반영되는지 확인합니다.

2. 좌표와 시간 설계

데이터기준
부지전역 중심 X/Z(m), 방향(°), 폭·깊이
공장부지 중심 기준 위치·방향. 부모 부지 회전과 합산
구역·셀각각 공장·구역 중심 기준. 회전된 네 모서리로 경계 검증
운송출발·도착 공장 ID, 공장 내 접점, 전역 경유점, 차량 종류, 요청 시점

X'=X부모+x cosθ−z sinθ
Z'=Z부모+x sinθ+z cosθ
X 동쪽, Z 남쪽의 상대 좌표입니다. 지리 좌표로 측량된 위치는 아닙니다.

경로 거리=접점→경유점→접점의 구간 길이 합. 적용 거리=자동 경로 또는 직접 거리. 이동 시간=적용 거리÷속도 또는 직접 시간. 완료 시간=요청+대기+상차+이동+하차.

직접 거리·시간이 화면 경로와 다를 수 있음을 표시합니다. 속도 단위는 m/분. 경로는 입력한 선분을 그대로 따르며 도로망·회피·회전반경·차량 충돌 검증은 없습니다.

3. 저장·복구와 원본 보존

스키마 p006-spatial-v1. 별도 localStorage 키로 저장하며 운영 Product Planner 데이터와 분리합니다. 이전 저장본 1개를 보관하고 현재 저장본 오류 시 복구를 제안합니다. JSON 가져오기 최대 2MB, 그룹별 최대 200개, 경유점 최대 100개.

입력 오류 시 마지막 유효 배치를 유지합니다. 미반영 입력이 있으면 재생을 막고, 부모·운송 참조가 남아 있는 삭제는 차단합니다. 브라우저 데이터 삭제·다른 PC에서는 JSON 내보내기가 필요합니다. 서버 저장·계정 동기화는 미연결입니다.

4. 3D와 실행

단일 Three.js WebGL 렌더러·공유 장면, 주 카메라+개별 부지/공장 카메라 최대 6개씩. 화면 밖에서는 렌더하지 않고 정지 상태에서는 변경이 있을 때만 다시 그립니다. DPR 상한 1.5. 공통 재생 시계와 타임라인을 사용합니다.

차량은 대기→상차→이동→하차→완료로 이동합니다. 완료 시 제품은 도착 접점에 남고 차량 숨김은 선택할 수 있습니다. 컨베이어는 경로에 고정되고 제품만 이동합니다. 모두 기능 검증용 단순 형상이며 실물 설비 GLB나 실제 차량 모델은 아닙니다.

생산 공정 완료 의존성·설비 동작·실제 완제품 형상·포장·녹화·GIS는 미연결입니다.
