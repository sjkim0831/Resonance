# P006 전체 베이스 검증 V3

## 원씽
204개 베이스 전체의 현재 내부 증거 기반 GEOMETRY 가능성 소진. 신규 모델·외부 요청·PLC 쓰기 없음.

## 조사와 판정
주체: Codex 검증기, 서버 실행 sjkim. 대상: 현재 resolver 666종, 204베이스, 447구성. 기존 740자료 내부 조사 재개 없음.
입력: 수정된 resolver, USD 현재 참조 계층, 기존 카탈로그 분석, 176/294 구축 근거, 제어 설계, 기존 10종 검증 장부.
출력: all204.json, all666.json, metrics.json, tests.json, preservation.json. 연결과 USD 원본 변경 없음.
1: 이미 기준 설계·핵심 형상 근거가 확보된 5베이스 10종 전 조건 재확인.
2: 제어 외함 설계 1베이스 20종 전수 대조. ID, 개별 prim, 치수, 바닥, 방향, 구성, 커넥터/디스플레이 기술 검사 통과. 장비별 핵심 형상 명세 미확보로 승격 보류.
3: 32베이스의 각 구성 서명, 설계 한계, 실제 하위 형상 목록 연결. 상이한 장비에 같은 외형이 쓰인다는 이유로 타입 적합 자동 상속 금지.
4: 160베이스는 참고 형상/생성 기록은 있으나 자산 ID-핵심 구성-치수-배치 기준의 적격 설계 연결이 부족. 생성 코드 및 자기 산출 bbox는 독립 검증 근거가 아님.
5: 원장비 6베이스는 실제 받침면 및 원장비 식별 필요. floor offset만으로 보정 금지. 연결된 6종이며 Track A 58종과 별도.

## 독립 증거
PHYSICAL: 실제 USD 물리 schema/joint 경로를 후보로 연결. 속성 존재는 하중/접촉/동역학 검증이 아님.
FUNCTION: 카탈로그 기능 요구와 USD timeSamples 연결. 요구 정의는 동작 시험 통과가 아님.
PORT: USD 포트 경로/위치/속성을 연결. 참조 앵커는 검증된 인터페이스가 아님.
수치상 부분 검증은 기술 검사만 뜻하고 GEOMETRY 단계의 일부 승격 상태가 아님.

## 회귀 검증
204개와 666개 누락/중복 검사. 10종 보존. 20종 /Catalog/ID 보존. /Catalog 루트 직접 참조 금지. 226 원본/종속 USD 해시 보존. resolver 해시 및 Track A 보존.
브라우저: 204/666 전환 → 분류 선택 → 검색 → 근거 조회 → 모바일 overflow 확인 → 스크린샷 검수.
정적 페이지 계정 인증 없음, 업무 데이터 쓰기 0. 실제 factory-studio/RTX E2E 실행 시험과 구분한다.
