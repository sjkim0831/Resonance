포트원 본인인증 연동 검증

KG이니시스 통합인증으로 인증창과 서버 검증을 확인합니다.

테스트 채널 · 실제 로그인 아님
인증 성공해도 계정 연결·권한 변경·로그인 세션 발급은 하지 않습니다. 이메일과 DI는 요구하지 않습니다.

1. 인증 동의 및 시작

선택한 인증기관에서 본인 인증을 직접 진행하세요. CCUS는 인증 결과를 서버에서 조회하고 CI 제공 여부만 확인합니다. 이 검증 화면은 개인정보 원문을 저장하거나 표시하지 않습니다.

대기 · 인증을 시작하지 않았습니다.

2. 화면 설계 · 도움말 · QA

업무 안내

동의 → 인증창 → 사용자 본인 인증 → 서버 결과 재조회 → 테스트 결과 확인. 인증창의 성공 메시지만으로 성공 처리하지 않습니다.

화면 설계

액터: 인증 대상 본인. 입력: 동의, 서버 발급 인증 ID, 일회성 확인값. 출력: 검증 성공 또는 실패. CI·이메일 원문, 로그인 토큰은 화면에 전달하지 않습니다. 인증은 10분 만료되며 완료 요청은 재사용할 수 없습니다.

QA 및 남은 작업

자동 검증과 실제 인증은 별개입니다. 실제 사용자 인증 결과는 위 상태 영역에 표시됩니다. 운영 로그인에는 실연동 채널, 계정 소유권 재확인, 계정 연결 저장 및 기존 권한·MFA 정책 통합이 추가로 필요합니다.
