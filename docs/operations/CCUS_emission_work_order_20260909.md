# 탄소배출 업무 — 페이지별 진행 순서

2026-09-09 · 사용자 검토 대기 · 아래는 개발/검수 순서이며 모든 사용자가 전부 거치는 필수 업무 순서는 아닙니다.

직접 탄소배출 경로 67개 + 공통 연계 3개 = 70개 검수 항목. 예정/생성형 64개와 메뉴 원본은 상세 기준 목록에 보존했습니다. 소스 경로 존재와 기능 동작 완료는 다릅니다.

등록 시 담당자·결재자는 필수로 받지 않는 것이 최신 설계입니다. 이미 있는 사업장·프로젝트는 재등록하지 않습니다. 프로젝트 ID가 필요한 상세 화면은 목록에서 선택하여 진입하세요.
