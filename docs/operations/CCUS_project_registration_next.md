# 배출량 프로젝트 등록 간소화 설계 및 현재 상태

## 원칙
등록은 프로젝트명, 서버에서 결정하는 회사, 참여 사업장 복수 선택, 산정 시작일·종료일, 선택 설명으로 구성한다. 업무 담당자 및 결재자 지정은 등록 필수가 아니다.

## 현재 반영
참여 사업장을 검색 가능한 작은 표로 변경했다. 복수 선택, 검색 결과 전체 선택, 선택 건수, 검색 전후 선택 유지가 가능하다. 실제 API가 제공하는 사업장명만 표시하며 코드·주소를 임의로 만들지 않는다.

## 아직 미반영
현재 서버 정책은 담당자 5명, Scope 및 산정 방법·마감일을 여전히 필수 검사한다. 이를 화면에서만 제거하면 저장 실패 또는 임의 기본값 저장이 발생하므로 기존 필드와 검사를 유지했다.

## 다음 서버 변경의 승인 조건
1. 등록과 산정 준비를 별도 상태로 분리한다. 등록 시 Scope·산정 방법 미설정은 허용하되 계산 전에 필수 검사한다.
2. 미지정 담당자를 생성자나 다른 직원으로 임의 배정하지 않는다. 생성자는 인증 세션에서 기록한다.
3. 등록만으로 자료 요청·임의 마감일·업무 완료 이력을 생성하지 않는다.
4. 회사와 활성 사업장 검사는 유지한다. 같은 회사 조회와 업무별 수정 권한은 각각 서버에서 검사한다.
5. 상세 및 각 후속 화면에 프로젝트 ID, 사업장 ID, 기간을 전달하고 교차 회사 접근을 차단한다.
6. 미산정 결과는 0으로 표시하지 않는다.

## 검증
UI 컴포넌트 검사는 테스트 데이터로 수행한다. 실제 인증 저장·재조회 및 다른 회사 접근 차단 검증과 구분한다. 현행 AGENTS 정책에 따라 인증 업무 검증과 명시적인 런타임 전환 전에는 backend/DB 변경을 운영에 적용하지 않는다.
