|기존 경로|새 실제 경로|
|---|---|
|/opt/Resonance/runtime/host-data/user-local|/opt/developer-tools/shared-user-local|
|/opt/Resonance/runtime/host-data/dev-runtime|/opt/ccus-runtime/backend|

기존 경로에 호환 심볼릭 링크를 남겼다. 이동 전 상대 링크가 이동 디렉터리 밖을 직접 가리키는지 검사했고, 이동 후 링크 3373개의 기존 대상 접근성을 확인했다. 새로 끊긴 링크 0개. 디렉터리 inode 동일 확인. 이동·링크 검사 스크립트 소요 1.98초이며 전체 작업 시간은 아니다.

검증: 주요 서비스 5개 active. 기존 python3에서 psycopg2 2.9.12 import 성공. CCUS 홈 브라우저 HTTP200, 제목 CCUS 탄소중립 플랫폼, 검사 오류0. 스크린샷의 헤더·메뉴·아이콘·도움말·QA·화면 설계·업무 길잡이 표시 확인. 로그인/PDF/P006 업무/AI 추론/전체 Python 패키지 검증은 미실행.
