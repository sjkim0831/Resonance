# 활동자료 사업장 귀속·열 매핑 반영 결과

## 구현
기존 `/emission/excel-upload?projectId=프로젝트ID` 화면에 추가. 신규 중복 페이지를 만들지 않았다.

1. 프로젝트에 연결된 사업장 선택. 단일 사업장은 자동 선택.
2. XLSX 파일 첫 시트의 첫 행을 제목으로 미리보기.
3. 활동자료명·구분·기간(YYYY-MM)·활동량·단위·증빙 비고의 원본 열을 각각 선택.
4. 최대 5행 매핑 결과 확인 후 저장.
5. 서버에서 사업장 연결·기간·필수값·수치 검사. 오류 시 전체 트랜잭션 취소.
6. 원본 파일·열 매핑·작성자·사업장·행 수 보존. 동일 프로젝트/사업장/파일/매핑 중복 요청 거절.

제한: XLSX 5MB, 자료 2,000행, 100열. 첫 시트만 지원. 한 파일은 한 사업장에 귀속. 임의 형식의 날짜/단위 자동 변환은 지원하지 않음.

## 상태
- Java 컴파일, TypeScript 검사 PASS.
- 실제 공통 컴포넌트의 미리보기·6열 연결·저장 버튼 조건·siteId/mapping 전송·저장 완료 표시 PASS. API는 테스트 응답으로 검증.
- 스크린샷 `ccus-column-mapping.png`: 예시 데이터 컴포넌트 검수이며 실제 저장 E2E 화면이 아님.
- DB 마이그레이션 적용. 기존 단일 사업장 자료 7건 귀속 보존.
- 서버 재시작 후 health UP, NRestarts=0.
- 실제 로그인 계정의 파일 저장·재조회·실패 롤백 E2E 미완료.

## 미완료
프로젝트 등록 화면의 필수 항목 단순화, 단계별 담당자 나중 지정, 여러 사업장의 결과 합계와 원본 다운로드 연결은 아직 남아 있다. 전체 프로세스 완료로 표시하지 않는다.

원본 파일 저장으로 건당 최대 5MB가 증가한다. 중복 파일은 같은 매핑·사업장 조합에서 저장 차단. 보존기간과 삭제 정책은 별도로 결정해야 한다.
