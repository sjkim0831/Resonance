# 회원 검증 스크립트 정식 경로 전환 검토

2026-09-08, 약2분. 파일/프록시/서비스 변경0건.

현재 프록시가 호출하는 run-member-domain-closure-fast-dev.sh 및 member-domain-design-fingerprint.sh는 인증서 워크트리에만 존재하고 /opt/Resonance/ops/scripts에는 없음.
추가 직접 검증 스크립트5개도 같은 상태. 초기7개 모두 현재 루트에 없음. 하위 릴레이/녹화/검증 파일8개도 현재 루트에 없음(중첩 의존성 전체 조사 아님).
설계 지문 스크립트는 지정 루트에서 git ls-files와 파일 SHA256을 계산한다. 따라서 루트만 바꾸면 다른 소스를 검증하게 됨. 검증 실행기는 STATIC/LIFECYCLE/CONTROLS/EXCEPTIONS를 실행하고 결과를 기록하며, 일부 릴레이는 실제 업무 실행 가능성이 있어 무단 실행하지 않음.

## 판단

단순 폴더 이동이나 프록시 경로 치환으로 해결할 수 없음. 현재 소스에 검증 도구를 이식하고 상대 경로/DB/테스트 계정/실행 대상 및 변경 효과를 검토해야 함. 과거 검증 통과 결과를 현재 코드 검증 결과로 표시하면 안 됨.
워크트리4.2GiB 삭제 보류. 이번은 읽기 전용 파일 검토라 신규 화면 검수 및 E2E 미실행. 기존 웹앱/DB/모델 보존.
다음 선택은 검증 도구 정식 이식 작업 또는 해당 폴더를 보존하고 다른 폴더 정리. 둘을 혼동하지 않도록 경로 변경은 보류함.
