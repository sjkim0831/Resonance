# P006 시나리오·기본 장면 로컬 DB 전환

2026-09-08. 신규 재구축 DB woosu_digital_twin에 기존 기능을 연결하는 후속 작업.

## 변경

scenario_store.py의 kubectl 시크릿/exec psql 호출을 환경변수와 psycopg2의127.0.0.1:35433 직접 연결로 전환. DB 접속5초, SQL10초 제한. 기존 세션 해시/역할/권한 검증 유지. 시나리오 입력 공정1~100개, 시간당 투입량0초과1000000이하, 공정시간0~86400, 불량률0~100 및 유한 숫자 검사 추가.

P006 웹 프록시의 기본 장면 경로2종(/r/P006/actuator/p006 및 /projects/P006/digital-twin/api)을 로컬 Java 백엔드18086으로 연결. 세션검증 없는 기존 Python 경로 대신 백엔드 세션검증 사용. 변경 요청은 신뢰 Origin 검사. 웹 서비스에 root-only DB 환경파일을 systemd로 주입. 파일에 비밀번호를 직접 적거나 출력하지 않음.

## 실제 검사10개 PASS

미인증 시나리오401 → 관리자 로그인 → 시나리오 조회200 → 음수 투입량400 → 투입량123과 검증용 이름 저장200 → 재조회 일치 → 원래 시나리오 복구 → 장면 조회200 → pump 좌표12/34 저장·재조회 → 테스트 객체 삭제. 검증 대상은 신규 DB이며 과거 데이터 복원 검증이 아니다.

최종 API+프로젝트 현황 브라우저 검사 명령 약2.35초. 프로젝트 현황 관리자 로그인 화면을 촬영하고 검수함. 별도로 factory-studio 화면 촬영은30초 제한을 초과했으므로 시각검수 실패/미완료로 남김. 이를 전체 페이지 PASS로 표시하지 않음.

## 남은 문제

공장 스튜디오 화면 지연 원인은 추가 진단 필요. 프록시 로그에는 integrity SLA worker exit2 반복이 확인돼 별도 자동화 스크립트의 구환경 의존성도 남아 있음. 시나리오·기본 장면 API만 로컬 전환했으며 설비·승인·USD/3D·나머지 메뉴 전체 완료가 아니다. QA 결과는 API10개PASS, 스튜디오 시각검수 미완료로 분리해야 한다.
